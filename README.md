# zammad-archive

Keeps a long-term, privacy-reduced, searchable copy of Zammad tickets that would otherwise
be deleted after 6 months.

- **export**: Zammad REST API (token) → configurable search queries → privacy middleware
  (allowlist, HMAC pseudonyms, scrubbing, quote/signature cutting, custom hook) → one folder
  per ticket with JSON + attachments
- **inspect**: look at real tickets (raw vs. processed + field report) before deciding what to keep
- **index**: archive → Meilisearch, plus a small static search UI served by Caddy
- **deploy**: rootless Podman Quadlets + a systemd user timer on RHEL 9

Docs:

- [Decisions and implementation plan](docs/ADR/README.md): start here
- [Setup guide (RHEL 9, rootless Podman)](docs/setup-guide.md)

## Quick start (workstation)

```bash
python3 -m venv .venv && .venv/bin/pip install .
cp config.example.yaml config.yaml        # set url, queries, internal_domains
export ZAMMAD_TOKEN=… ZAMMAD_ARCHIVE_SECRET=$(python3 -c "import secrets;print(secrets.token_hex(32))")
.venv/bin/zammad-archive check
.venv/bin/zammad-archive inspect --limit 20     # → inspect-out/report.md (contains raw personal data!)
```

Commands: `check`, `inspect`, `export [--full] [--dry-run] [--query-name N]`,
`index [--all] [--reset]`, `meili-setup`, `run` (export + index, used by the timer).

## Development

```bash
python3 -m unittest                     # unit + end-to-end tests against a fake Zammad
python3 -m tests.fake_zammad 8099       # fake Zammad for manual runs (token: test-token)
```

Runs on Python ≥ 3.9 (RHEL 9 system Python). Dependencies: `requests`, `PyYAML`.

## Layout

```
zammad_archive/   cli, zammad (API client), middleware (privacy), textconv, exporter,
                  inspector, indexer (Meilisearch), archive (file layout), extract (Tika)
web/              static search UI (config.js is generated by meili-setup)
deploy/           Caddyfile, Quadlet units, systemd timer, env example
examples/         custom middleware hook
docs/             ADRs + setup guide
tests/            unittest suite + fake Zammad server
```
