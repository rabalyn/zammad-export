# zammad-archive

Keeps a long-term, privacy-reduced, searchable copy of Zammad tickets that would otherwise
be deleted after 6 months.

- **export**: Zammad REST API (token) → configurable search queries → privacy middleware
  (allowlist, HMAC pseudonyms, scrubbing, quote/signature cutting, custom hook) → one folder
  per ticket with JSON + attachments
- **inspect**: look at real tickets (raw vs. processed + field report) before deciding what to keep
- **index**: archive → Meilisearch, plus a small static search UI served by Caddy
- **deploy**: everything with rootless **podman-compose** on RHEL 9, nightly systemd user timer

## Quick start

```bash
cp deploy/env.example .env && chmod 600 .env      # token + two random secrets
cp config.example.yaml config.yaml                # zammad.url, queries, internal_domains
mkdir -p data/archive/tickets data/meili local
podman-compose build exporter && podman-compose up -d
podman-compose run --rm exporter inspect --limit 20 --out local/inspect-out   # look before you keep
podman-compose run --rm exporter meili-setup
podman-compose run --rm exporter run --full
# search UI: http://localhost:8080
```

Commands (`podman-compose run --rm exporter <command>`): `check`, `inspect`,
`export [--full] [--dry-run] [--query-name N]`, `index [--all] [--reset]`, `meili-setup`,
`run [--full]` (export + index, used by the timer).

No real Zammad at hand? `dev/zammad-dev.sh up` starts a local one with dummy tickets.

## Development

```bash
python3 -m unittest                     # unit + end-to-end tests against a fake Zammad
python3 -m tests.fake_zammad 8099       # minimal fake Zammad for quick manual runs (token: test-token)
dev/zammad-dev.sh up                    # a real Zammad 7.2 with dummy data (podman-compose)
```

The CLI also runs without containers: `pip install .` then `zammad-archive -c config.yaml …`
(Python ≥ 3.9, dependencies `requests`, `PyYAML`).

## Layout

```
compose.yaml      meilisearch + web (Caddy) + exporter
Containerfile     exporter image (UBI 9, Python 3.12)
zammad_archive/   cli, zammad (API client), middleware (privacy), textconv, exporter,
                  inspector, indexer (Meilisearch), archive (file layout), extract (Tika)
web/              static search UI (config.js is generated by meili-setup)
deploy/           Caddyfile, systemd timer, env example
dev/              local test Zammad with dummy data
examples/         custom middleware hook
docs/             ADRs + setup guide
tests/            unittest suite + fake Zammad server
```
